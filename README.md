# E-Invoice GoLive Tracker

Global e-invoicing go-live dates, waves and deadlines from 2025 to 2028.

- Main link: https://einvoicecalendar.web.app (Firebase project `einvoicecalendar`)
- Backup link: https://ajay25101991.github.io/einvoice-tracker/
- Data: `data.json` in this repo, refreshed every Monday, Wednesday and Saturday at 1 PM IST.
  The Firebase page reads this file on every load, so do not rename or delete this repo.
